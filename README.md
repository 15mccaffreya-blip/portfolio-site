# Portfolio Website

A responsive portfolio website with a dark theme, left-side navigation, fixed per-page GIF-to-colored-ASCII backgrounds. Built with plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Run it

Open `index.html` in a browser. The site works as a standalone static website with no local server required.

## Pages

- `index.html` is the home page. The top-left wordmark links here.
- `projects.html` has a Projects landing hero followed by five sticky, viewport-height case studies. Each case study has title, photo, aims, methods, and technologies.
- `about.html` has an About me title and biography followed by Experience, Education, Certifications, and Interests. Experience lists five roles with logo and short-description; Education has three entries with logo, level, and subject/grade.
- `contact.html` contains the Contact section.
